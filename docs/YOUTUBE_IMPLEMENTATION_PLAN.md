This supplements the per-video scoreboard. It is an implementation plan, not a claim that everything shipped. No paid resources, paid API connections, model training or bulk external communication are included.

## Slice 1: explicit specs and honest review coverage
`spec_plan`, tests, and refusal of over-budget partial code reviews. Full 40-video ledger and license/product planning sources. PR #213.

## Slice 2: learn without trusting or drowning in source text
- `skill_inspect`: offline location/category risk hints for download-and-run, secrets, hidden actions and destructive directions. No safety certificate.
- `video_learn`: JSON3 caption parser, real timestamp citations, original URL, repo extraction, scanned untrusted text. Untimed transcripts stay untimed. Retrieval needs actual captions; it does not pretend a summary is a transcript.
- `evidence_index`: exact line evidence, bounded output, all-source search, explicit unmatched sources and clipping. Original data stays available. No Elastic-licensed code copied.
- `review_receipt`: separate builder/reviewer labels, full expected-file coverage, fail/unknown checks. Caller claims remain unverified.
- `motion_storyboard`: word timestamp to frame planning, source-only numbers, scene bounds, reduced-motion and rendered-frame checks. It is not a rendering engine.
- `writing_profile`: authorized sample-only rhythm metrics. No identity inference, model training, retained private text or external upload.

## Slice 3: useful capability wiring, not duplicate stacks
- Unlimited-OCR: optional local model adapter supplied by the owner, no auto-download or trust_remote_code execution. Validate image bounds (PDF model pipeline remains absent), require a configured audited model loader and return unavailable honestly. Verify model-license and hardware needs before live scoring.
- Paperclip/AX/OpenRig: a dependency-ordered team/task manifest with task ownership, work-state transitions, per-task budgets, output references and pause state. Existing orchestration remains the executor. No Kubernetes server or employee-agent swarm installed.
- PR Lens: change graph export from the actual diff/code map, typed nodes/edges, escaped labels and added/modified/deleted status. No model-generated diagram called ground truth and no paid GitHub app installation.
- Hindsight/codeg: scoped structured experience records with facts/evidence/observations, verification/failure provenance and controlled retirement. Preserve the current memory pool's tenant boundaries; never silently share facts across people. Benchmark comparison distinguishes hosted LLM pipelines from local memory baselines.
- WeKnora/Univer: document evidence retrieval and Office workflows built on existing ingest/OfficeCLI. Optional editor runtime is not bundled into a messaging-only deployment without a consumer.

## Research corrections to keep in runtime guidance
- Lost in Conversation paper (https://arxiv.org/html/2505.06120v1): 39% average performance decline in simulated underspecified multi-turn tasks, not deliberate degradation or a universal per-chat timer. Preserve constraints and source evidence across handoffs; restarting alone is not a proved cure.
- Hindsight (https://arxiv.org/abs/2512.12818): vendor benchmarks need task/configuration/cost context. Do not market the noesek memory layer as achieving their numbers without rerunning the same evaluation.
- Open Code Review (https://arxiv.org/html/2608.09290v2): deterministic stages do not make model judgments deterministic. Line anchoring, file coverage and verification are independent gates.
- Paywalls: see YOUTUBE_PRODUCT_PLAN.md. Subscription access never grants permission for messages, purchases or ad spend.
